## Short description (one sentence)

```
Free, open-source download manager for Windows with multi-connection downloads, FTP, scheduling, a browser extension and an MCP server that lets AI assistants such as Claude operate it.
```

## Description

```
Anabranch splits each download across up to 32 parallel connections and resumes from the saved offsets after a dropped connection or a restart. It handles HTTP, HTTPS, FTP and FTPS, and HLS and DASH video streams, which are merged into one MP4 file with FFmpeg.

A scheduler runs queues between set times on chosen weekdays, then quits, sleeps or shuts down the computer. Downloads that need a login prompt for HTTP Basic, Digest or FTP credentials, which are stored encrypted. The browser extension for Chrome, Edge and Firefox hands downloads to the app together with the site's cookies, and lists the video streams a page plays.

Anabranch includes a Model Context Protocol (MCP) server. Claude Desktop, or any other MCP client, can check links, queue and schedule downloads, supply logins and report progress for you, through a local API protected by a token.

The app is suited to large scientific and GIS datasets (satellite scenes, elevation models, climate archives), which are often served over FTP or behind portal logins. It is MIT-licensed, updates itself from GitHub Releases, and is also available as a portable exe and through Scoop.
```
